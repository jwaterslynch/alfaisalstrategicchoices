Strategic analysis of student survey responses for MGT 490: Strategic Management.

## Contents

- `index.html` — Interactive dashboard with story layer + evidence explorer
- `Alfaisal_Survey_Analysis.xlsx` — Master data file with all 652 coded responses

## Analysis Summary

- **113 students** surveyed across 8 strategic questions
- **652 total responses** with qualitative coding
- **Human-audited** January 2026

### Key Findings

- **Q4 (Defensibility):** 59% see conditional/partial threat — students are nuanced, not binary
- **Q8 (Avoid):** 56% explicitly warn against rapid expansion
- **Strategic Signal:** Differentiate through depth, not scale
